1. To run our SQL code, please copy and paste the code into any SQL testing website/software available.
    (For this example we used, DB Fiddle to test our code)
   
2. You will copy our given code into the "Schema SQL" side or the Left Side
   
3. Then you will input values for any table (Customer, Order, Book, etc) into the the same "Schema SQL" side or the Left Side

4. Then on the Right Side or the "Query SQL" side you will search for what you want to find from the values you have inputted
   
       For example "SELECT * FROM Book;", this SQL Query code will retrieve all the data from the given table, for this example it would be all the data from the 'Book' table
